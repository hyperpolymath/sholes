= Coaptation — the typed descriptile↔contractile face-off
:toc: macro
:toclevels: 3

*Coaptation* keeps a repository's *descriptiles* (the descriptive "what-is":
the repo deed `<repo>_chora.deed`, including its `(anchor …)` clause) in homeostasis with its
*contractiles* (the normative set-point: Intend / Must / Trust / Adjust + Dust /
Bust). The runner `coapt` is the controller of the cybernetic loop.

The name is clinical: _coaptation_ is the bringing of two surfaces into correct
matching contact — a healing fracture, a heart valve's leaflets sealing under
pressure. That is exactly the face-off: do the descriptive facts seal against the
normative obligations? The deeper "why" — *stability through change*, re-anchoring
rather than holding a fixed set-point — is *allostasis*; see `ALLOSTASIS` notes
when that doc lands. This pack is the _Coaptation_ mechanism; _allostasis_ is its
philosophy.

toc::[]

== The idea: a typed relation, not a text diff

Contractiles emit *obligations* (clauses); descriptiles emit *evidence* (facts).
The correspondence is a *typed relation that only inhabits when evidence witnesses
obligation*, not a string comparison. In the Idris2 sound core
(`core/Coaptation.idr`):

[source,idris]
----
data Holds        : List Fact -> Spec -> Type         -- the looked-up fact satisfies the spec's predicate
data Witness      : List Fact -> List Spec -> Type    -- a NON-EMPTY spec list, every spec holding
data HardResolved : List Fact -> WMap -> Clause -> Type  -- ByWitness | ByDeferral; no gap constructor
----

What is proved, kernel-checked by `idris2 --check` and gated through
`just proof-check-idris2` (`verification/proofs/idris2/MANIFEST`):

* `hardGateSound` and `hardGateComplete`: the Must/Trust gate function returns
  `True` exactly when every hard clause carries a `HardResolved` term. A
  witness holds the actual fact the lookup finds and a proof that its
  predicate is true.
* `mustCannotGap` and `trustCannotGap`: no gap permission exists for the hard
  verbs, for any clause.

What is *not* proved: that the Idris2 model is a faithful transcription of the
Nickel comparator `coapt.ncl`. That bridge is argued in the core's comments
(PROOF-POLICY status `ASSUMED`), and `coapt.ncl` stays the authoritative
reading. The model also records today's behaviour honestly: a hard clause with
a runnable probe and no witness is `probe-deferred` and does not fail the Yard
gate (`ByDeferral`). The standards ultraplan (P2.1) rules that such clauses
become blocking until a Hunt run reports; the core drops `ByDeferral` then.

`coapt.ncl` treats a witness-map entry with an empty witness list as refuted (it would
otherwise read as witnessed with no evidence); the soundness proof depends on
that rule.

== The cybernetic loop is the k9 ladder

[cols="1,1,4"]
|===
| Tier | Role | Here

| *Kennel* (pure data)
| SENSOR
| `extract-clauses.sh` + `extract-facts.sh` parse the contractiles and
  descriptiles into deterministic JSON atoms with stable IDs.

| *Yard* (pure eval)
| COMPARATOR
| `coapt.ncl` runs Coverage/Witnesses over the atoms, grades per verb, and emits
  the graded *coaptation receipt* (TOML). The face-off lives here; pure, no side
  effects. `verify.sh` + `coapt.k9.ncl` are the Yard drift gate.

| *Hunt* (guarded exec)
| ACTUATOR
| `coapt.sh` writes the receipt and — only when red — assembles a re-anchor
  *basis*. The only tier allowed to act; leashed. It never drops an anchor.
|===

== Grades are per-verb, not one Boolean

[cols="1,4"]
|===
| *Must*   | Boolean gate — every witnessed obligation must hold; a refuted or unmeasured Must is a hard fail.
| *Trust*  | Boolean gate + *provenance* — the witness carries the content hash of the descriptile source.
| *Adjust* | Graded posture in [0,1] — *advisory*, never a hard gate (accessibility / inclusive design).
| *Intend* | Tropical (min-plus) *distance-to-north-star* — count of committed intents not yet `done`. Wishes (horizon aspirations) are not drift.
| *Bust*   | Alarm — a recognised break; alarms only when its witness shows the failure is _active_, distinguishing it from a merely declared mode.
| *Dust*   | Expected — planned exnovation; reported, never alarms.
|===

The aggregate, judged against the Intend/Must/Trust tolerances in `grades.ncl`, is
the "how far is too far" that proposes a re-anchor: `green` (nothing) /
`amber` (advisory) / `red` (assemble re-anchor basis).

== Files

[cols="1,3"]
|===
| `extract-clauses.sh` | Normative-side atomiser. Lifts the records of the `declaration` field of the six `<verb>/<verb>.k9.ncl` files (`nickel export` piped to `jq`) into `clauses.json` (stable id `verb.slug`). Reader only.
| `extract-facts.sh`   | Descriptive-side atomiser. Projects the repo deed (through `scripts/deed-field.sh`), including its `(anchor …)` clause, into `facts.json` (stable id `family.key`). The family prefixes `clade.` `state.` `ecosystem.` `agentic.` name the deed clauses that replaced the retired CLADE / STATE / ECOSYSTEM / AGENTIC records (rsr-template-repo#209) and are kept so the witness map does not change. `neurosym.` and `playbook.` facts come from the `(neurosym …)` and `(playbook …)` clauses. Each prefix is a `Family` constructor in `core/Coaptation.idr`, lower-cased.
| `witness-map.ncl`    | The hand-authored *knowledge* layer: which fact witnesses which clause, under what predicate. The one file to review for honesty.
| `grades.ncl`         | Grade type per verb + aggregation tolerances.
| `coapt.ncl`          | The Yard comparator. Imports the atoms + map + grades; emits the receipt (`nickel export --format raw`).
| `coapt.sh`           | The runner/controller. `--report` (SITREP) / `--reanchor` (assemble basis).
| `verify.sh`          | Yard drift gate. Regenerates the receipt and byte-compares the committed one.
| `coapt.k9.ncl`       | k9 contract (Yard) documenting + validating the drift check. Sibling of `arrival-pack/claude-md.k9.ncl`.
| `receipts/latest.toml` | The committed coaptation receipt — the drift baseline.
| `core/Coaptation.idr`  | Idris2 sound core: a model of the Must/Trust gate, proved sound and complete against a content-bearing witness relation, with no gap for Must/Trust. Gated by `just proof-check-idris2`. Not yet fed the runner JSON, so the Nickel reading stays authoritative (build-path step 6).
|===

== Usage

[source,sh]
----
just coapt              # --report: emit the coaptation receipt (decides nothing)
just coapt-reanchor     # --reanchor: assemble a re-anchor basis IF the band is red
just validate-coapt     # Yard drift gate: fail if the committed receipt is stale
----

== Honest gaps (do not paper over these)

* *The Yard reading is partial — and on this repo, mostly deferred.* It judges only
  what the descriptiles attest. Of the clauses (the receipt's clause count), only a
  handful are directly descriptile-witnessed (the receipt's `descriptile-witnessed` count); the Must and
  Trust obligations are overwhelmingly filesystem/git probes reported
  `probe-deferred`. *Trust in particular has ZERO descriptile witnesses* — the
  descriptive self-model carries no security/provenance evidence — so the whole
  Trust gate defers to Hunt. A Hunt-tier run is required for a full hard-gate.
* *The Nickel prototype does NOT make an unwitnessed Must a hard error.* In the
  authoritative Nickel reading today, a Must with a probe but no descriptile witness
  is soft `probe-deferred`, not red; only a Must with neither witness nor probe
  (`unmeasured`) trips red. The Idris2 core (`core/Coaptation.idr`) proves the gate model sound and
  complete, and that Must/Trust have no gap, for all inputs. It does not govern
  the Nickel reading until it is *wired* to consume the runner's JSON (build-path
  step 6's remaining sub-step); the model-to-Nickel bridge is argued, not proved.
* *Bust has no descriptile witness.* The three bust clauses used to read
  the retired STATE record's open-failures / last-result, which held hand-written values that no
  maintenance run updated. The deed has no such field, so they are unwitnessed and
  read `latent` exactly as a witnessed non-alarm would: `latent` is not `checked`.
* *The anchor has no drift/ledger schema yet.* The deed's `(anchor …)` clause (`hyperpolymath.anchor/1`)
  encodes semantic-authority + golden-path, not a recognised-drift / re-anchor
  ledger. So `--reanchor` assembles a basis but cannot record the drop; wiring the
  ledger is the prerequisite for a real re-anchor branch.
* *The contractile runner toolset is known-broken* estate-wide; Coaptation does not
  depend on it — it reads the K9 declarations directly — but it does not fix it either.
* *The witness map is declarative.* The Idris2 core proves what a witness must
  carry, but which fact witnesses which clause is still a human judgement in
  `witness-map.ncl`, and it must be kept honest.
