[#what-this-is]
== What this is

**sholes** is a formally verified bidirectional canonicalization engine for content-addressed storage (Git, IPFS, hermetic build systems, and container mounts).

It neutralizes line-ending discrepancies (`LF` vs `CRLF`) at the storage boundary using **algebraic quotient types mechanized in Agda** (with exported proof objects for **Lean 4** and **Coq/Rocq**) and a **zero-allocation, Creusot-verified streaming Rust engine**.

Instead of relying on fragile regexes, error-prone `core.autocrlf` configurations, or 200-line `.gitattributes` files, **sholes** proves that all platform representations factor through a unique canonical projection, rendering line-ending corruption mathematically impossible.

[#the-historical-tragedy]
=== The Historical Tragedy (1868–Present)

In 1868, **Christopher Latham Sholes** patented the practical typewriter. When typists reached the right margin, two distinct mechanical events occurred:

1. A physical lever was slapped to slide the heavy carriage back to the left margin (**Carriage Return**, `CR`, `\r`, `0x0D`).
2. A rubber cylinder rolled the paper up by one line (**Line Feed**, `LF`, `\n`, `0x0A`).

A century later, the early computing split cemented this mechanical legacy:
* **Unix (1970s)**: Dennis Ritchie and Ken Thompson dropped the redundant byte, standardizing on **`LF`**.
* **CP/M and MS-DOS**: Retained teleprinter compatibility with the two-byte sequence **`CRLF`**.

Because Git hashes raw byte streams ($\Sigma^*$) rather than semantic contents, humanity has spent fifty years paying for this split with:
* Phantom 40,000-line Git diffs when files are opened across OS boundaries.
* Wiped `git blame` histories.
* Linux containers crashing because shebangs search for `/usr/bin/env bash\r`.
* Poisoned cryptographic build caches in Nix, Bazel, and IPFS.

[#the-mathematical-fix]
=== The Mathematical Solution

We do not negotiate with ASCII `0x0D`. **sholes** treats content addressing as a quotient over an equivalence relation on byte streams:

$$\mathcal{Q} = \Sigma^* / \sim_{\mathrm{LE}}$$

1. **Mechanized Proofs (Agda / Lean 4 / Coq)**:
   * **Idempotence**: $\forall s.\; \mathrm{canon}(\mathrm{canon}(s)) \equiv \mathrm{canon}(s)$
   * **Equivalence Invariance**: $\forall s_1, s_2.\; s_1 \sim_{\mathrm{LE}} s_2 \implies \mathrm{canon}(s_1) \equiv \mathrm{canon}(s_2)$
   * **Cryptographic Coherence**: $\forall H, s_1, s_2.\; s_1 \sim_{\mathrm{LE}} s_2 \implies H(\mathrm{canon}(s_1)) \equiv H(\mathrm{canon}(s_2))$
   * **Binary Preservation**: $\forall s.\; \mathrm{is\_binary}(s) \implies \mathrm{canon}(s) \equiv s$
   * **Well-Behaved Symmetric Lens**: Satisfies the categorical `GetPut` and `PutGet` laws for environment-directed routing.
2. **Verified Systems Engine (Rust + Creusot)**:
   * Zero-copy, bounded-buffer streaming filter.
   * Native Git packet-line protocol driver (`filter.clean` / `filter.smudge`).
   * Optional FUSE/9P virtual filesystem layer for cross-OS transparent checkouts.
