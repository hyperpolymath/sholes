= rsr-template-repo Roadmap

The journal of the template itself: milestones, blockers and next actions.
A repo minted from the template does not inherit it: `just repo-init`
replaces this file with `build/templates/ROADMAP.adoc.in`.

Phase and maturity are not recorded here. They live in the repo deed,
`rsr-template-repo_chora.deed`, in the `(status …)` and `(maturity …)`
clauses (`just state-phase` prints both).

This file took over the journal half of the retired STATE record
(rsr-template-repo#209), last
updated there on 2026-09-19. STATE also recorded version 0.3.0; the release
version is 0.1.0 (`Justfile`, `CITATION.cff`, tag `v0.1.0`, deed
`(meta :version …)`).

== Blockers

. Hypatia M-3: `mix hypatia.rsr_score --standards` resolves the SSOT at the
  pre-reorg path (`rhodium-standard-repositories/spec/`). A one-line fix is
  prepared (recon P0.2/01), pending its PR. The dogfood job works around it
  with an explicit `--ssot` until then.
. Estate-wide `actions.lock` sweep (D38/D39 ruling 2026-09-19): the grace
  window closed on 2026-10-01. The sweep's estate-wide status is not recorded
  here. This repo's own lockfile verifies (`gh actions-lock --no-fix`, rc=0,
  2026-10-02).
