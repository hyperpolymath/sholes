proofs under `verification/proofs/` remain a separate estate gate. This status
file does not claim a prover run when the corresponding toolchain is absent.

== Commands

[source,bash]
----
# Rust implementation and property tests
cargo test --workspace

# Publication-facing Agda, Lean 4, and Coq/Rocq checks
bash scripts/check-publication-proofs.sh

# Existing estate proof gate (Idris2, Lean4, Agda, Coq)
just proof-check-all
----

A missing toolchain is a failure, not a successful skip. Generated compiler
caches and Why3 sessions are build artifacts and are not proof deliverables.
The Rust tests are correspondence tests, not a substitute for the mechanized
proofs.
